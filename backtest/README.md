# 백테스트

무한매수법 V2.2 · 떨사오팔 · 종사종팔4 를 과거 실데이터로 돌려본다.
**조회 전용**이다. 운영 매매 코드는 `import` 만 하고 한 줄도 바꾸지 않는다.

## 핵심 원칙 — 규칙을 다시 쓰지 않는다

매매 규칙을 백테스트용으로 재구현하면 운영 코드와 조용히 어긋난다.
그래서 각 전략의 운영 `trading_logic.generate_orders()` 를 **그대로 호출**한다.
DB 모델 대신 같은 필드를 가진 가벼운 객체를 넘길 뿐이다(읽기만 하므로 안전).

따라서 운영 규칙을 바꾸면 백테스트 결과도 자동으로 따라간다.

체결·상태갱신은 각 전략의 운영 `simulate.py` 와 동일하게 맞췄다. 한 군데만 다르다:

| 항목 | simulate.py | worker.py (실운영) | 여기 |
|---|---|---|---|
| QUARTER 1회 매수금 | `min(B, 누적매도×0.3/10)` | `min(B, 예수금/10)` | **worker 쪽** |

simulate.py 는 예수금을 추적하지 않아 대용식을 쓴다. 백테스트는 예수금을 추적하므로
실운영 공식을 따른다.

## 웹 UI

```bash
python -m backtest.server
```

→ http://127.0.0.1:8777 . 전략·티커·기간·시드·파라미터를 바꿔가며 돌려본다.
127.0.0.1 에만 바인딩한다(외부 비공개). 운영 대시보드(`main.py`)와 완전히 별개의 앱이라
운영에 영향이 없다.

## CLI

```bash
python -m backtest.cli -s infinite -t TQQQ --seed 5000 --start 2020-01-01
python -m backtest.cli -s infinite -t SOXL --preset --compound
python -m backtest.cli -s ddsop    -t TECL --preset
python -m backtest.cli -s jongsa   -t UPRO --preset --v4-compound
python -m backtest.cli --cost SOXS          # 다운로드 비용 견적만
python -m backtest.cli --list               # 받아둔 티커
```

주요 옵션

| 공통 | 설명 |
|---|---|
| `-s/--strategy` | `infinite` · `ddsop` · `jongsa` |
| `-t/--ticker` | 티커. 없으면 자동으로 받는다(과금) |
| `--start/--end` | 기간 (YYYY-MM-DD) |
| `--seed` | 시드 ($) |
| `--fee` | 편도 수수료 % (0.25 = 0.25%) |
| `--preset` | 운영 설정값으로 덮어쓰기 |

| 무한매수법 | | 떨사오팔·종사종팔 | |
|---|---|---|---|
| `--A` | 분할수 | `--tranches` | 트렌치수 |
| `--R` | 목표수익률 % | `--x` | x % |
| `--compound` | 복리모드 | `--losscut` | 손절 거래일 |
| | | `--seed-reflect` | 씨드반영 |
| | | `--v4-compound` | [종사] 익절복리 |

## 가격 데이터

Databento 일봉(`ohlcv-1d`). LOC/MOC 는 **상장거래소 종가단일가**에서 체결되므로
통합피드가 아니라 그 종목의 상장거래소 데이터셋을 쓴다(티커별로 자동 판별).

- 커버리지는 **2018-05-01** 부터다. 그 이전은 Databento 에 없다.
- 처음 쓰는 티커는 비용을 먼저 보여주고(웹 UI) 확인 후 받는다. 일봉은 종목당 약 $0.003.
- 받은 데이터는 `_cache/` 에 저장되어 이후 네트워크를 타지 않는다.

### API 키

소스에 적지 않는다. 둘 중 하나로 준다.

```bash
export DATABENTO_API_KEY=db-...        # 환경변수
echo "db-..." > backtest/_dbn_key.txt  # 또는 파일 (gitignore 대상)
```

## 분할·병합

Databento 는 체결 당시 **원시가격**을 준다. 분할을 반영하지 않으면 분할일에 가격이
반토막 나면서 거짓 폭락 → 거짓 추가매수 → 거짓 손실이 연쇄로 생긴다.

- `splits.VERIFIED` — 웹 공시와 데이터 역추적이 **둘 다 일치**한 종목 (SOXL·SPXL·TECL·TQQQ·UPRO·QLD).
- 그 밖의 티커는 `splits.autodetect()` 가 데이터에서 직접 찾는다.
  판별식은 `전일종가 ÷ 당일시가`. 분할이면 이 값이 비율에 가깝고, 실제 폭락이면
  시가가 전일종가 근처에서 열리므로 ≈1 이다. 2020-03 코로나 폭락 오탐 0건을 확인했다.
  역분할(병합)도 같은 식으로 잡는다(SOXS 1:10 ×4, 1:20 ×1 탐지 확인).

조정 체인이 맞는지는 **조정된 마지막 종가 vs 실계좌 현재가**로 검증했고 6종목 모두
오차 0.22% 이내였다.

## 읽을 때 주의할 것

1. **기간이 한 번뿐이고 그 한 번이 강세장이다.** 2018-05 이후만 본다. 3배 레버리지가
   90% 넘게 녹는 국면(2000·2008)이 표본에 없다. 단순보유 쪽 숫자를 미래로 옮기면 안 된다.
2. **LOC 체결을 종가로 단순화했다.** 종가가 주문가 이하면 전량 체결로 본다.
   실제 종가단일가에서는 부분체결·미체결이 생긴다. 참조가는 전일종가를 썼다.
3. **세금·환전·배당이 빠졌다.** 수수료는 `--fee` 로 넣을 수 있다(운영 설정은 0).
4. **미청산 포지션은 마지막 종가로 평가**해 최종자산에 넣는다.
5. **예수금 부족으로 거부된 매수**가 있으면 경고로 표시한다. 무한매수법 후반전은
   ☆%가 음수로 내려가 1/4을 손실 매도하므로 예수금이 규칙상 필요액 밑으로 떨어질 수 있다.
   실계좌에서도 KIS 가 거부하는 상황이라 그대로 반영했다.
